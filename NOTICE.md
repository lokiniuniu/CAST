# External projects

This source release does not vendor Matrix-Game, Light Interaction, checkpoints,
datasets, evaluation packages, or generated media.

The Matrix integration was developed against Matrix-Game commit
`71c3cd7f741311f8100f6cf9cde942b6c1378d11` and Light Interaction commit
`a5825201c1251628deae5d3196e207a41f16e23c`. Their code and assets must be
obtained from the upstream projects under their own terms. Some CAST modules
import Matrix's `wan` package at runtime.
